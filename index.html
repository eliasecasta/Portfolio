02 / AI-assisted engineering

AI accelerates the work.
Standards make it reliable.

I use coding agents to speed up implementation, exploration and test-writing — not to outsource responsibility. I define requirements, review architecture, maintain clear boundaries and verify outputs before a release is considered complete.

Working software is the deliverable. Readable, testable and maintainable engineering is the method.

01 — Understand the real problem

Client goals, constraints, existing behavior and measurable acceptance criteria.

02 — Design the system and context

Architecture, integration contracts, repository instructions and change specifications.

03 — Direct AI-assisted implementation

Delegate scoped changes with relevant codebase context and explicit boundaries.

04 — Verify, don't assume

Linting, type checks, unit/integration tests, browser E2E, review and risk-based gates.

05 — Own the release

CI/CD, environment isolation, deployment verification, observability and documented follow-up.
